# ThreatForge SYR — كشف التهديدات الرقمية وتوثيق الأدلة الجنائية

منصة ويب **محلية بالكامل (Local-first)** تعمل بدون إنترنت: تُدخل نصاً أو صورة لقطة شاشة لعملية ابتزاز/تهديد/احتيال/انتهاك خصوصية، فتستخرج النص (بالعربية والإنجليزية عبر OCR)، وتحلّله بمحرك قواعد وزني حتمي، وتربط الواقعة بمواد **قانون الجريمة المعلوماتية رقم 20/2022**، وتولّد تقريراً جنائياً PDF مع حزمة أدلة مشفرة مقاومة للتلاعب — كله على جهاز المستخدم دون رفع أي محتوى خارج الجهاز.

---

## المتطلبات النظامية

| المكوّن | الحد الأدنى / الإصدارة | ملاحظات |
|---|---|---|
| Python | **3.13** (تم التحقق على 3.13.0 / Windows) | بيئة `venv` موصى بها |
| Tesseract OCR | **5.x** (بناء UB-Mannheim على Windows) | يُكتشف تلقائياً — لا حاجة لإضافته إلى PATH |
| خط TTF عربي | Arial / Segoe UI (ويندوز) أو DejaVu (لينكس) | يُستخدم في توليد PDF ورسم صور الاختبارات |

> **حزمتا اللغة `ara` + `eng` مضمّنتان داخل المشروع** في `data/tessdata/` — التطبيق يضبط `TESSDATA_PREFIX` برمجياً عند أول تشغيل، فلا تحتاج تثبيت حزم لغات إضافية.

## التثبيت

```bash
# 1) إنشاء بيئة افتراضية
python -m venv .venv

# 2) تفعيلها (Windows — Git Bash / CMD / PowerShell)
source .venv/Scripts/activate        # Git Bash
.venv\Scripts\activate               # CMD
.\.venv\Scripts\Activate.ps1         # PowerShell

# 3) تثبيت الاعتماديات (مقفولة الإصدارات — راجع requirements.txt)
pip install -r requirements.txt
```

### إعداد Tesseract (التعرف التلقائي)

- **Windows:** ثبّت بناء UB-Mannheim من صفحة الإصدارات على GitHub. إذا مُثبّت في المسار الافتراضي `C:\Program Files\Tesseract-OCR\` فسيعثر عليه التطبيق تلقائياً.
- **Linux/macOS:** `apt install tesseract-ocr` (أو `brew install tesseract`)، وأضف الحزمتين `tesseract-ocr-ara` / `tesseract-ocr-eng`.
- **اختياري:** أضف مساراً مخصصاً للثنائي في `config.py` (قائمة `TESSERACT_CANDIDATES`).
- إذا لم يوجد الثنائي، تعرض الواجهة رسالة واضحة (بالعربية) بدل الانهيار، وتواصل العمل عبر مسار **لصق النص** مباشرة.

## التشغيل

```bash
streamlit run app.py
```

افتح المتصفح على `http://localhost:8501` — تبدأ رحلة S0→S7:

1. **S0 الادخال** — الصق نصاً أو ارفع صورة (PNG/JPG حتى 15MB).
2. **S1 OCR** — استخراج النص من الصورة (ara+eng) مع معالجة مسبقة.
3. **S2 تطبيع** — تنظيف النص (إزالة التشكيل، توحيد الهمزات والتاء المربوطة).
4. **S3 تحليل** — درجة خطر 0–100 مع نطاق (منخفض/متوسط/مرتفع/حرج) + قائمة الأدلة المقتبسة. النطاق **الحرج** يستدعي لافتة تحذير فورية.
5. **S4 توصيف قانوني** — الفئة ← مادة المرسوم 20/2022 مع صياغة استرشادية.
6. **S5 التقرير** — PDF جنائي (نص أصلي + نص مستخرج + صورة البكسلات الأصلية + طابع UTC + القسم القانوني).
7. **S6 التشفير** — عبارة سرية → حزمة أدلة: `report.enc` (AES-256-GCM، PBKDF2-600k) + `manifest.json` (SHA-256 للادلة) — أي تعديل يفسد المصادقة.
8. **S7 الدليل** — دليل استجابة سريعة + رقم تتبع الحالة.

## التحقق من النزاهة (الأدلة)

تُحفظ كل قضية في `storage/evidence/<التاريخ>/SYR-YYYYMMDD-NNNN/`:
- `report.enc` — **الحزمة الحجّة** (نص مشفر مُصادق GCM).
- `manifest.json` — بصمات SHA-256 للـ PDF والصورة الأصلية + وصف الخطر + المواد القانونية.
- `report.pdf` + `original.png` — **نسخ مساعدة** للعرض فقط؛ أي تلاعب بها يظهر عبر انكسار البصمة.
- `verify_integrity()` تفحص الحزمة كاملة وترجع تقريراً (`all_ok`).

**Privacy:** العبارة السرية لا تُخزَّن أبداً؛ كل شيء يبقى على جهازك.

```

features/analysis/nlp.py       # S2: تطبيع + tokenize عربي
features/analysis/redflags.py  # S3: محرك قواعد وزني (data/redflags.toml)
features/legal/mapping.py      # S4: فئة ← مادة (data/legal_mapping.toml)
features/report/generate.py    # S5: PDF جنائي RTL عربي
features/evidence/encrypt.py   # S6: AES-256-GCM + PBKDF2 + SHA-256 sidecar
data/redflags.toml             # أنماط الخطر وأوزانها (قابلة للتعديل بلا كود)
data/legal_mapping.toml        # خريطة الفئات ← المواد القانونية
data/arabic_stopwords.txt      # stopwords عربية مضمّنة (بلا تنزيل)
data/tessdata/                 # ara + eng traineddata (محمول)
tests/                         # 8 ملفات — 40 اختباراً
```

### النشر على Streamlit Cloud / حاويات Linux

- **لا حاجة لـ `packages.txt` لإضافة خطوط**: المشروع يضمّ خطاً عربياً مضمّناً (`data/fonts/NotoNaskhArabic-Regular.ttf`) يضمن توليد PDF حتى في صورة نظام بلا أي خطوط — ويُستخدم تلقائياً كملاذ أخير في `FONT_CANDIDATES`.
- تأكد فقط من وصول `data/fonts/` و`data/tessdata/` مع حزمة النشر (لا تحذفهما في أي `.gitignore` مخصص للنشر).
- ثنائي Tesseract على الحاويات: `apt-get install -y tesseract-ocr tesseract-ocr-ara tesseract-ocr-eng` (أو وضع الحزمتين في `packages.txt` لـ Streamlit Cloud).

## إخلاء المسؤولية القانونية

أرقام المواد والتصنيف إجرائي/استرشادي لأغراض التوثيق والمساعدة، **وليس فتوى/استشارة قانونية ملزمة**. يجب التحقق من النص الرسمي للقانون عبر جهة مختصة (مكتب محاماة أو فرع مكافحة الجريمة المعلوماتية) قبل التقديم القضائي. **في حالات الابتزاز الجارية:** لا ترسل أي مبالغ، احتفظ بالأدلة كاملة، وبلّغ فوراً عبر السلطات المختصة/فرع مكافحة الجريمة المعلوماتية.

## تطوير المستقبل (خارج النطاق الحالي — موثق في PROJECT_MAP)

- شهادة وقت موثقة (NTP/TSA) بدل UTC ساعة النظام.
- ربط برمجي حقيقي بالجهات (واجهة HTTP) بدل رقم التتبع الحتمي.
- إدراج تصنيف الذم/القدح بعد حسم تعارض المصادر القانونية.
